# AI アシスタント

Anthropic の Claude API を使って、記事の作成を手伝います。使わなくても、ほかの機能はすべて使えます。

## できること

- **添削**: 誤字脱字や分かりにくい表現を直した本文を提案します。変更点を差分で確認してから適用でき、適用後も元に戻せます
- **抜粋・タイトル・スラッグ・カテゴリー・タグの案**: 候補を選ぶと入力欄に入ります。各入力欄の ✨ ボタンからも呼び出せます
- **下書きの作成**: テーマやメモから、タイトル・本文・抜粋・タグをまとめて作ります
- **独自のプロンプト**: よく使う指示をボタンとして登録できます

## 使い方

1. [Claude Console](https://platform.claude.com/) で API キーを作ります
2. タイトルバーの歯車の「アプリの設定」→「AI」で登録します。キーはこの PC のキーチェーンに保存されます
3. サイトごとの設定（使うモデル、執筆方針、独自のプロンプト）は、左メニューの「AI」で行います。執筆方針（文体や読者像）は、すべての機能に反映されます

## 料金

料金は Console で前払いしたクレジットから引かれ、残高がなくなると止まります（自動チャージは購入画面でオフにできます）。左メニューの「AI」で、日ごと・モデルごとの使用量の目安を確認できます。
