# 準備とトークン

## 必要なもの

- Cloudflare アカウント（無料プランで使えます）
  - R2 は、アカウントごとに一度ダッシュボードで有効にしておきます
  - workers.dev のサブドメインが未設定なら、ダッシュボードの「Workers & Pages」を一度開いて設定します
- Cloudflare の **ユーザー API トークン**（下記）

## ユーザー API トークンを作る

アプリで使うのは **ユーザー API トークン** です（アカウント API トークンではありません）。

1. Cloudflare ダッシュボード右上のアイコンから **My Profile → API Tokens** を開きます
2. **Create Token** → **Create Custom Token** を選びます
3. 権限を追加します（下の表）
4. **Account Resources** で使うアカウントを選び、トークンを作ります
5. 表示されたトークンをアプリに貼り付けます

| 権限 | 必須 | 何に使うか |
|---|---|---|
| Account · D1 · Edit | はい | サイトのデータベースを作る・削除する。記事や設定を読み書きする |
| Account · Workers R2 Storage · Edit | はい | 画像とテーマを置くバケットを作る・削除する。ファイルを読み書きする |
| Account · Workers Scripts · Edit | はい | サイトを公開する（Worker の作成・更新・削除） |
| Account · Turnstile · Edit | 問い合わせフォームを使うとき | フォームの不正送信を防ぐ Turnstile のウィジェットを作る・削除する |
| Account · Account API Tokens · Edit | GitHub 連携を使うとき | GitHub Actions 用のトークンを作る・削除する |

あとから使う機能の権限は、そのときにトークンを編集して足せます（足りなければアプリが案内します）。

## アプリが使うトークン・キーの一覧

| トークン・キー | 作る人 | 何に使うか | 置き場所 |
|---|---|---|---|
| Cloudflare のユーザー API トークン | あなた | アプリが Cloudflare を操作する | この PC のキーチェーン |
| Claude の API キー（任意） | あなた（[Claude Console](https://platform.claude.com/)） | AI アシスタント | この PC のキーチェーン |
| GitHub のトークン（GitHub 連携） | あなた | ワークフローの起動と、Actions のシークレットの設定 | 予約用の Worker のシークレット |
| GitHub Actions 用の Cloudflare トークン | アプリ（アカウント API トークン） | GitHub Actions からサイトを公開する | GitHub の Actions のシークレット |
| Turnstile の秘密鍵（問い合わせフォーム） | アプリ（ウィジェットと一緒に） | 送信が人によるものか確かめる | 保存しない（公開のたびに Cloudflare から取り出して Worker に渡す） |
| Basic 認証のパスワード（任意） | あなた | 閲覧者を限る | 保存しない（D1 にはソルト付きのハッシュだけ） |

- キーチェーンは、Windows の資格情報マネージャーや macOS のキーチェーンです。設定ファイルに平文で保存することはありません
- Windows では、アプリのロック（「アプリの設定」→「セキュリティ」）を有効にすると、キーチェーンのトークンとキーを Windows Hello で暗号化します
- GitHub 連携のトークンの詳細は [GitHub 連携](github-actions.md) を参照してください

## 初めての公開まで

1. アプリを起動し、ユーザー API トークンを貼り付けて Cloudflare に接続します
2. 「サイトを追加」で、サイト名とサイト ID を入力します
   - サイト ID は英小文字・数字・ハイフンです。Cloudflare のリソース名（`zwa-<サイトID>` など）に使われ、後から変更できません
   - D1 データベースと R2 バケットが作られます。Worker は初めての公開のときに作られます
3. 記事を書き、「プレビュー」で確認して、「サイトに公開」を押します

別の PC から同じサイトを使うときは、「サイトを追加」→「既存のサイトに接続」で選びます。サイトの設定は D1 にあるので、どの PC からも同じです。

サイトが不要になったら、「サイト情報」→「Cloudflare」→「サイトを削除」で、アプリが作ったリソース（Worker・R2・D1 など）をまとめて削除できます。元に戻せません。
