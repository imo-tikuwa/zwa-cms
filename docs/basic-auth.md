# Basic 認証

公開前の確認や、関係者だけに見せたいときに、サイト全体にユーザー名とパスワードをかけられます。

## 使い方

1. 「サイト情報」→「Basic 認証」で、ユーザー名とパスワード（8 文字以上）を入力して「設定する」を押します
2. 「サイトに公開」すると、サイトを開いたときにブラウザがユーザー名とパスワードを尋ねるようになります

外すときは「オフにする」を押してから、もう一度「サイトに公開」します。プレビューには認証はかかりません。

## パスワードの扱い

- パスワードそのものはどこにも保存しません。サイトの D1 に、ソルト付きのハッシュ（SHA-256）だけを保存し、Worker はそれと照らし合わせます
- そのため、設定したパスワードを後から表示することはできません。忘れたら設定し直します
- D1 にあるので、別の PC や GitHub Actions（予約投稿）から公開しても、同じ認証がかかります
- 閲覧者に伝えるものなので、ほかで使っているパスワードにはしないでください

## Workers の利用量

ふだんの公開サイトは静的ファイルとして配信され、Worker は動きません。Basic 認証が有効な間は、すべてのリクエストを Worker が確かめるため、Workers のリクエスト数に数えられます（無料プランは 1 日 10 万件まで）。

- 認証を通っていないアクセスは、ページ 1 回につき 1 件です
- 認証を通った閲覧者は、画像や CSS も 1 件ずつ数えられます。CSS や画像はブラウザに保存されるので、2 ページ目からは減ります

限られた人に見せる程度なら、まず上限には届きません。
