# 問い合わせフォーム

固定ページの下に、問い合わせフォームを置けます。使わなければ、サイトに Worker の処理は増えません。

## 使い方

1. 「サイト情報」→「問い合わせフォーム」で有効にします。このサイト用の Turnstile のウィジェットが作られ、左メニューに「問い合わせ」が出ます
   - API トークンに `Account · Turnstile · Edit` の権限が必要です（足りなければアプリが案内します）
2. 「問い合わせ」でフォームを作ります。項目は 1 行・複数行のテキスト、メールアドレス、電話番号、プルダウン、ラジオボタン、チェックボックス、同意のチェックから選べます。フォームはいくつでも作れます
3. 固定ページの編集画面の「問い合わせフォーム」で、表示するフォームを選びます。ページの URL は固定ページのスラッグなので、`/contact/` でも `/support/` でも構いません
4. 「サイトに公開」すると、フォームがサイトに出ます

## 送信されたら

- 送信内容はサイトの D1 に保存され、「問い合わせ」の受信一覧で読めます。ほかのサービスには送られません
- アプリの起動中は 5 分ごとに確認し、ウィンドウを閉じている間に届いたらデスクトップに通知します。メールでの通知はありません
- 送信を受けるのは公開サイトの Worker（`/_zwa/forms/<ID>`）です。Worker が動くのは送信のときだけで、ほかのページは今まで通り静的ファイルです

## 不正な送信の防ぎ方

- Cloudflare Turnstile（無料）で、人による送信か確かめます
- ボットだけが埋める見えない入力欄、送信元のページの確認を行います
- 同じ送信が二重に保存されることはありません

プレビューでは Turnstile のテスト用のキーを使い、送信はできません。

## 無効にするとき

「サイト情報」→「問い合わせフォーム」で無効にすると、次の公開からフォームが消え、Turnstile のウィジェットは削除されます。作ったフォームと受信した内容は残ります。

送信内容には個人情報が含まれます。不要になったものは削除し、必要に応じてサイトにプライバシーポリシーを載せてください。
